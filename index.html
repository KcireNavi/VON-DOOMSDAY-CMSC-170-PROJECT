Problem statement and motivation

Describe the task in one sentence: predict whether a landslide event is fatal from its category, trigger, size, setting, location and date. Then explain why it matters: lives, homes, roads and early warning for communities.

Dataset

Source: agency or portal, link, access date.

Size: 9,648 events after dropping rows with a blank fatality_count.

Target: fatal = 1 if fatality_count > 0, otherwise 0.

Features: 9 in total: landslide_category, landslide_trigger, landslide_size, landslide_setting, location_accuracy, latitude, longitude, month, logpop.

The full dataset is too large to show here. Open the full dataset.

Preprocessing

Rows with a blank fatality_count were dropped. Blank categorical values were set to “unknown” and one-hot encoded. Blank numeric values were filled with the median, and all numeric features were standardized. All done with the csv module and NumPy.

Methods

All three methods are implemented from scratch with Python and NumPy.

Naive Bayes

How it works and how we implemented it: short explanation.

Why we chose it: a fast probabilistic method that works well with the one-hot encoded categorical features such as landslide category, trigger and size.

k-nearest neighbors

How it works and how we implemented it: short explanation.

Why we chose it: it makes no assumptions about the data and tests whether landslides with similar characteristics and nearby locations tend to share the same outcome.

Decision tree

How it works and how we implemented it: short explanation.

Why we chose it: it captures combinations of features, such as a large landslide in a populated area, and its rules are easy to read.
